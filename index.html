      🎓 아이디어 출처 / Idea origin

      한국어

      이 개념은 이일국(Dr. Lee Il-guk) 교수의 용인대학교 창업 수업에서 나온 한 우수 학생의 아이디어에서 출발했습니다. 원래 아이디어에 포함되어 있던 의료 영상(X선) 요소는 안전·규제상의 이유로 완전히 제거하고, 자동 세정·건조·체위 변경·생체신호 추정 모니터링이라는 재택 케어 개념으로 다시 구성했습니다. 문장 복사 없이 처음부터 새로 작성한 클린룸 구현이며, 개인정보(PII)는 포함하지 않습니다. 아이디어를 나눠 준 학생에게 감사드립니다.

      English

      This concept originated from a standout student idea in Dr. Lee Il-guk's entrepreneurship class at Yongin University. The original idea included a medical-imaging (X-ray) element, which has been entirely removed for safety and regulatory reasons. It was reframed as a home-care concept for assisted washing, drying, repositioning, and (simulated) vital-sign monitoring. This is a clean-room implementation written from scratch with no copied sentences and no personal data (PII). With gratitude to the student who shared the idea.

      기여: Dr. Lee Il-guk (이일국), LWJ, LMJ, Claude · 라이선스: 코드 Apache-2.0 / 문서 CC BY 4.0
